# Authentic Peds Remaster — GTA San Andreas

This folder contains **301 AI-remastered diffuse textures** as individual 1024×1024 PNG files. The original textures in the repository root remain unchanged.

يحتوي هذا المجلد على **301 خامة محسّنة** بصيغة PNG ودقة 1024×1024. الصور الأصلية في جذر المستودع لم تتغير.

## Known limitations / ملاحظات

- `SkinID8.png` is the initial version; the corrected rectangular-source version could not be generated. نسخة SkinID8 هي النسخة الأولى وليست النسخة المصححة.
- Original IDs **31, 40, 45, 63, 92, 140, and 178** could not be generated due to generation restrictions. **145** failed for technical reasons. These eight remasters are not in this folder; their original textures remain in the repository root.
- IDs **74, 149, and 208** are absent from the original source files.
- Generated images may not perfectly preserve UV alignment. Test each texture on its in-game model before use. محاذاة UV غير مضمونة؛ يرجى اختبار الخامات داخل اللعبة.
